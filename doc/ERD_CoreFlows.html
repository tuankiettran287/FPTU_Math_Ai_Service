ERD & Core Flow — bản đúng theo code hiện tại

Đối chiếu với entity & controller thật trong BE_KLTN (.NET 9, Clean Architecture). Dùng thay cho các sơ đồ vẽ theo thiết kế docx cũ. Field ở dạng mono = tên thuộc tính thật trong Domain.

2 DbContext: MainDb (math_tutor_main_db3) · QuestionBankDb (fptu_mathai_final) Role: Admin · Teacher · Student Embedding: bge-m3 · VECTOR(1024)

Vì sao các slide ERD hiện tại sai

Dự án đã refactor lớn sang mô hình tự học thuần: đã bỏ hẳn Campus Semester Course Class Lesson Assignment Submission CourseMaterial Enrollment Cohort. Không có SuperAdmin/AdminCampus — chỉ 3 role. Question Bank là 1 bảng JSONB với embedding là cột vector (không phải bảng riêng, không phải 1536 chiều).

FLOW 1

Giải bài với AI Tutor

Đúng · bổ sung
SVMở AI Tutor → nhập đề (text) hoặc upload ảnh / file (PDF·DOCX) → chọn chế độ Full / Hint
FEPOST /api/ai/solve · { problem_text?, image_base64?, file_base64?, mode, language }
BETạo AiConversation+AiMessage · ghi AiInteractionLog(Pending) → gọi IAiServiceClient.SolveProblemAsync
AINếu có ảnh/file → OCR / trích text (LaTeX) → LLM DeepSeek-R1 suy luận → trả JSON { final_answer, steps[], answer_check } theo đúng ngôn ngữ câu hỏi
BECập nhật log (IsSuccess, LatencyMs, TokensUsed) → trả FE
SVXem lời giải từng bước / gợi ý → hỏi tiếp (conversation) → học từ lỗi sai
Bổ sung so với slide: ngoài ảnh còn nhận file PDF/DOCX; câu trả lời tự khớp ngôn ngữ (VI/EN); lưu hội thoại AiConversation + AiMessage (không chỉ AiInteractionLog).
FLOW 2

AI Service Interaction (BE → AI)

Đúng
BENhận request → tạo AiInteractionLog (Type, RequestPayloadJson, status = Pending)
DBLưu log Pending
BEGọi IAiServiceClient (timeout + retry)
AIXử lý tác vụ: Generate · Solve · Grade · RAG · OCR · Embed → trả JSON
BEThành công → cập nhật ResponsePayloadJson, IsSuccess=true, Latency, Tokens; lỗi → IsSuccess=false, ErrorMessage
BEXử lý business (lưu Attempt / cập nhật progress…) → trả FE
FLOW 3

Tự học (Đăng ký → Làm bài → Progress)

Sửa bước đăng ký
SVVào My Study → chọn Môn + Giáo viên → đăng ký học
BETạo SelfStudyProgress (StudentId + SubjectId + TeacherId) → lưu DB
SVXem LectureVideo + Document theo chương → xem video cập nhật VideoWatchHistory
SVLàm bài rút từ SelfStudyExamPool
BETạo SelfStudyExamAttempt → chấm MCQ tự động → cập nhật ScorePercent
DBCập nhật ChapterProgress + SelfStudyProgress (%, streak)
SVXem tiến độ % hoàn thành + streak
Sai ở slide: đăng ký tạo StudyGroupMember (role = SelfStudy) → thực tế phải là tạo SelfStudyProgress(Student + Subject + Teacher). Tự học là mô hình đa-giáo-viên, không đi qua Study Group; StudyGroupMember cũng không có trường role.
FLOW 4

Đấu trường — Trận 1v1 / Cuộc thi

Đúng · lưu ý AI
SVVào Arena → chọn tham gia 1v1 hoặc Cuộc thi
BEGọi ArenaQuestionClient / ArenaContestService sinh câu theo ELO
AISinh câu hỏi → snapshot vào ArenaMatchQuestion / ArenaContestQuestion
BETạo ArenaMatch / ArenaContestParticipant + bản ghi làm bài
SVLàm bài (có anti-cheat) → BE chấm MCQ tự động, ghi AntiCheatLog nếu vi phạm
DBCập nhật điểm + tính lại ELO → ghi ArenaEloHistory · ArenaProfile
SVXem kết quả + Ranking → xem lại câu sai (deep-link Hỏi AI Tutor)
Lưu ý thực trạng: AI sinh câu hỏi chưa nối xong → hiện fallback rút MCQ từ Question Bank. ArenaGeneratedQuestion chỉ là DTO, không phải bảng.
FLOW 5

Đăng nhập & Bảo mật (2FA)

Thiếu · nên thêm
SVĐăng ký bằng Email + OTP hoặc Google (GV/Admin do quản trị tạo)
FEPOST /api/auth/login — nhập FEID hoặc Email + mật khẩu
BEKhớp FEID || Email → nếu bật 2FA → trả pending-token (chưa cấp JWT)
SVNhập mã TOTP (Google Authenticator) — bắt buộc Admin, tùy chọn GV/SV
BEXác thực TOTP → cấp JWT + RefreshToken · ghi LoginHistory (location/device)
FLOW 6

RAG — Hỏi đáp tài liệu & Ra đề bằng AI

Thiếu · nên thêm
GVAdmin/GV upload tài liệu → lưu R2 → DocumentController gọi ai-index
AI/documents/ingest → chunk + embed → AiIndexStatus = Indexed
SVHỏi tài liệu: POST /api/ai-search/ask
BELọc Document hợp lệ (Published + IsAiSearchable + Indexed) → gửi allowed_document_ids
AIRetrieve chunk theo vector → trả lời kèm trích nguồn
GVRa đề tự do: nhập prompt → SelfStudyExamController.Generate → AI generate_questions → tạo SelfStudyExamPool
